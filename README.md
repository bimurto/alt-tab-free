# AltTab Free

A fork of [AltTab](https://github.com/lwouis/alt-tab-macos) with every feature free: Search, extra shortcuts, the App Icons and Titles styles, and Auto Size. It has no Pro tier, trial, license or automatic updates.

## Install

1. Download `AltTab-Free-<version>.dmg` from [Releases](https://github.com/bimurto/alt-tab-free/releases/latest).
2. Open it and drag AltTab into Applications.
3. Launch AltTab. The app isn't notarized, so the first launch is blocked: open System Settings → Privacy & Security and click Open Anyway.
4. Grant Accessibility and Screen Recording when asked.

Requires macOS 12 or later.
